# box2d-deterministic

Box2DWeb 2.1 ported to an ES module that simulates deterministically in all JavaScript engines.

# Installation

With npm:

```npm install box2d-deterministic```

In the browser:

```html
<script type="module">
  import { Box2D } from "https://cdn.jsdelivr.net/npm/box2d-deterministic/box2d.js";
</script>
```
